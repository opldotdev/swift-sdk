# Compatibility evidence

This directory owns the evidence used to plan and verify behavioral parity.
The files are research inputs, not claims that features are implemented.

- [Go SDK v1.3.3 surface inventory](GoSDK-v1.3.3.md)
- [BRC requirements matrix](BRC-Matrix.md)
- [Compatibility rulings](Rulings.md)

Every implementation packet must link the applicable rows, test vectors,
error-category mapping, and any approved ruling. A public API is not frozen
while a behavior it exposes remains listed as unresolved.
