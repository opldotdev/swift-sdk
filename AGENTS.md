# Reference implementations

This package ports `@bsv/sdk` and `go-sdk`. It does not invent protocol.

| Kind | Path |
|---|---|
| Specifications | `~/code/BRCs` |
| TypeScript | `~/code/ts-stack/packages/sdk` (`@bsv/sdk`) |
| Go | `~/code/go-sdk` |

Read those checkouts before you change behaviour. Match the live reference, not
a remembered API. If TypeScript and Go disagree, cite `~/code/BRCs` or a live
vector and keep one behaviour.
