# Conformance fixtures

Only permissively licensed or public-domain fixtures may be committed here.
Every fixture group must have a uniquely named fragment under `Manifests/`
recording provenance, version/commit, content hashes, transformation notes,
and its governing notice or license under `Licenses/`. The loader merges these
fragments deterministically and rejects undeclared files or duplicate entries.

Open BSV Go SDK fixtures and unlicensed BRC examples are not copied here. Go SDK
parity is exercised through the external oracle under `Tools/Conformance`.
